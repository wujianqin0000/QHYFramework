# Glossary {#glossary}

| Term | Meaning |
|---|---|
| AOT | IL2CPP assembly compiled to native code ahead of time |
| HotUpdate | Managed DLL downloaded and loaded at runtime |
| Supplemental metadata | Stripped AOT DLL data for HybridCLR generics |
| Package | Independently versioned YooAsset resource set |
| Address | Stable logical asset name |
| Collector | Editor rule selecting assets for a package |
| Manifest | Versioned asset/bundle/dependency/hash index |
| Bundle | Downloadable resource archive |
| Handle | Asset or scene lifetime token |
| HostPlayMode | Built-in first package plus remote CDN |
| EditorSimulateMode | Fast editor-only simulated manifest |
| Full Package | Resources, DLLs, AOT, and Player build |
| HotUpdateOnly | Code/resource build without a Player |
| latest.json | Pointer to the latest full client |
| Baseline | Published client version/AOT/signing record |
| UPM | Unity Package Manager package format |
