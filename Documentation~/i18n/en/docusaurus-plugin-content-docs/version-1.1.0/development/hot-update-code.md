# Write hot-update code {#hot-update-code}

Place gameplay scripts under `Assets/Game/Scripts/HotUpdate`, inside
`Game.HotUpdate.asmdef`.

```csharp
using UnityEngine;
using UnityEngine.UI;

namespace Game.HotUpdate
{
    public sealed class HotUpdateTextDemo : MonoBehaviour
    {
        [SerializeField] private Text targetText;
        private void Start() =>
            targetText.text = "Game.HotUpdate v1.0.1 is running.";
    }
}
```

Attach it to Main and assign the UGUI Text. No assembly marker is required.
Keep Editor APIs out of runtime code, declare new assembly references in the
asmdef, and migrate renamed serialized fields with `FormerlySerializedAs`.

**Expected:** starting from Boot executes the component in Main. An invalid DLL
Address usually means generated bytes were not built/collected; rebuild through
the Release window.
